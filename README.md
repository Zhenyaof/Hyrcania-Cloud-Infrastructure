# Hyrcania Cloud Infrastructure

## Overview

Hyrcania Cloud Infrastructure is a cloud infrastructure project designed to demonstrate the deployment and management of enterprise-grade infrastructure on Microsoft Azure using modern DevOps and Infrastructure as Code practices.

This repository documents the complete lifecycle of the project, including Azure architecture, networking, Docker containerization, and Terraform automation.

---

## Objectives

- Learn Microsoft Azure Infrastructure
- Design secure cloud networking
- Deploy and manage Azure resources
- Use Docker for containerization
- Automate infrastructure using Terraform
- Document a real-world cloud project
