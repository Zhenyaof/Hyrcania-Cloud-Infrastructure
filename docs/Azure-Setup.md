# Azure Infrastructure

## Overview

This document describes the Azure infrastructure created for the Hyrcania Cloud Infrastructure project.

The environment was built manually to understand Microsoft Azure fundamentals before introducing Infrastructure as Code with Terraform.

---

## Azure Services Used

- Resource Group
- Virtual Network (VNet)
- Subnets
- Network Security Groups (NSGs)
- Storage Account
- Azure Files
- Blob Storage
- Virtual Machines
- Azure Monitor
- Log Analytics Workspace
- Azure CLI

---

## Learning Objectives

- Understand Azure resource organization
- Design a secure virtual network
- Configure network segmentation using subnets
- Secure workloads using NSGs
- Deploy and manage storage services
- Learn Azure monitoring services
- Manage Azure resources using Azure CLI

---

## Architecture

The Azure environment follows a layered network design separating infrastructure into multiple subnets for security and scalability.
